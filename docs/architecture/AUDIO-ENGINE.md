# Unified Audio Engine
Ports: TtsService.synthesize(request, cancel) -> staged WAV; VoiceRegistry.acquire(model_id, version) -> lease; AudioCache.lookup(key)/publish(staged,key); AudioJobManager.submit(request)->job_id, cancel(job_id); PlaybackController.play(artifact_id, generation), pause/resume/stop/seek(ms)/set_rate(rate); RecordingService.start(device_id), stop(save), cancel (R3.A). AudioEngine facade emits job_state(job_id,state), job_finished(job_id,result), playback_state(generation,state), position_changed(generation,ms), error(code,correlation_id). Worker never manipulates widgets.
Request immutable: job_id, session_id, generation, text, locale, model ID/version/hash, synthesis params, purpose. Accept one nonblank word, preserve display paragraphs. Separate normalization version, do not discard punctuation indiscriminately. Cache SHA256 canonical UTF-8 JSON of normalized text, normalization version, model/config hashes, engine version and synthesis settings. Playback rate excluded from synthesis key; length_scale included if used. Initial cache cap 512 MiB LRU unleased items; oversized result not cached; active artifacts leased. One loaded TTS voice initially, release between jobs when switching.
Jobs: QUEUED -> RUNNING -> SUCCEEDED/FAILED; QUEUED -> CANCELLED; RUNNING -> CANCELLING -> CANCELLED (or FAILED if cleanup fails, diagnostic). Atomic arbitration cancel vs publish under manager lock; after terminal state cancellation no-op. Generation invalidation suppresses autoplay even if already succeeded. Worker stage files, validate RIFF PCM nonempty and header/data consistency, close and atomically publish. Batch summary succeeded/failed/cancelled per item; no false overall success.
Playback states STOPPED, LOADING, PLAYING, PAUSED, ENDED, ERROR. One active source; changing source increments generation and stops prior playback/timer. Ignore callbacks for old source using generation-bound connections/controller token. Qt errors surfaced; seek clamped; speed 0.5–1.5 step .05 candidate, verify actual support and disclose pitch preservation. Do not silently substitute synthesis rate for playback rate.
Training session state table:
IDLE + start -> PREPARING; PREPARING + matching ready -> PLAYING; PLAYING + natural end -> WAITING if pause required else ADVANCING; WAITING + timer -> ADVANCING; ADVANCING increments repeat or sentence then PREPARING, or COMPLETED; active + pause -> PAUSED (remember previous state and remaining monotonic timer); resume restores previous state, pending ready handled once; stop -> CANCELLED; failure -> FAILED; new selection cancels old and creates new generation. Manual skip invalidates pending timer and audio. Infinite repeat never auto advances until skip/stop. 1–10 finite repeats; pause 0–10 seconds. Listen & Repeat pause after each play including last before advance; Shadowing default no pause; Text and Sentence default one play. Natural media end only advances; user stop does not. Persist sentence ID/revision and next repeat; resume after crash from sentence start, not stale timer.
Recording R3.A: Qt audio input, choose supported format, convert to mono PCM16 WAV at supported sample rate; ASR resamples separately. Default max 10 min per attempt, configurable lower limit; show elapsed and peak, clipping diagnostic not speech score. Permission denial, device loss, disk full -> fail safely, no successful DB record; allow user to keep valid partial audio explicitly. A/B sequential playback, same chosen reference revision/model, never compare waveforms as pronunciation accuracy. TTS sample rate native. Recording audio never cache-evicted.
Tests: single word, multilingual Unicode, long text/chunks, cancel before/during publish, old callbacks, zero pauses, infinite stop, pause during preparation/wait, batch partial failures, corrupt WAV, device loss, disk full, cache hit/miss/version and LRU leased files.
