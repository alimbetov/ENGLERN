# Model lifecycle
Manifest fields: schemaVersion=1, modelId, type TTS/ASR, engine, locale, version, sourceRevision immutable upstream commit/tag digest, license SPDX or explicit license URL/text, files [{role,path,url,sizeBytes,sha256}], engineCompatibility. TTS requires exactly one MODEL and CONFIG; ASR bundle includes all runtime-required files. Each hash 64 lowercase hex, size positive, relative safe paths, HTTPS allowlisted source; no mutable main URLs. Actual manifest values verified R1/R3.C; placeholders never installable.
States NOT_INSTALLED -> DOWNLOADING -> VERIFYING -> READY or FAILED/CANCELLED. READY -> CORRUPT if integrity fails; READY -> RETIRING -> NOT_INSTALLED after leases release. Update new version independent; active pointer changes only after verification and smoke. Download into same-filesystem staging directory; enforce per-file size, total space (bundle + staging + reserve 100 MiB), validate TLS, timeout and cancellation, hash both ONNX and JSON, validate config and engine load + sample WAV. Atomically rename complete version directory then transactionally update active pointer. Crash before pointer switch leaves recoverable orphan; startup reconciliation never activates unverified bundle. Old version retained until lease count zero, then explicit cleanup. Verify on install and before first load per process; invalid -> no synth, repair prompt. Concurrent install same version deduplicated. No auto execution of downloaded scripts, no user recording upload. ASR downloads explicit, local_files_only equivalent after install. Model licenses verified before distribution; download consent, size and disk use visible.
Tests: tampered hash/config, missing file, interrupted download, version rollback, simultaneous install, active lease deletion, crash before/after rename, no internet with READY model, failed smoke.
