# Learning content and exercise contract
Canonical UTF-8 JSON schema v1 in learning-content.schema.json; validate schema then semantic rules: unique sentence/exercise IDs, references resolve inside revision, nonblank after trim, valid BCP47 tags, source/license declared, max lengths per CORE-11. Unknown schema version rejected with actionable error; no silent conversion. Import TXT preserves paragraph breaks and proposes segmentation; abbreviations (Dr., e.g.), decimals, quotes, punctuation tested; user can correct before save. Original source text and sentence order stored; display vs TTS normalization separate. Imported user content marked private; bundled content requires redistribution rights. Revision increments on edit; existing sessions pinned to old revision; duplicate same hash no-op, conflict preview, no overwriting immutable revision.
Exercises: READING displays text; LISTENING hides text optionally; SENTENCE uses selected sentences; LISTEN_AND_REPEAT and SHADOWING use shared session state machine; DICTATION hides text, accepts typed response, reveals reference and token diff; COMPREHENSION supports single-choice or self-assessed open response; RETELLING/SPEAKING record optional prompt and self-assess, no reference WER for free speech. Grammar in context via lesson notes and comprehension; no standalone grammar engine in v1.0. Lesson includes level/topic/objectives, optional translation, focus words, IPA source, examples. Initial catalog 18 lessons (3 per A1–C2), editorial review for level, natural language and rights; not a complete accredited curriculum.
Scoring: dictation normalized word tokens (Unicode NFKC, casefold, punctuation handling preserving internal apostrophes, whitespace collapse; numbers not expanded by default); version normalization. Levenshtein with deterministic tie-break substitution, deletion, insertion; WER=(S+D+I)/N, may exceed 100%; N=0 -> N/A; no rounding until display. Comprehension exact choice correctness; open answers self-assessment. ASR uses same versioned normalization for scripted tasks, reports recognition discrepancy not pronunciation defect. WPM = recognized tokens / elapsed valid recording seconds *60; zero duration N/A. Pause metrics only after qualified VAD; report method/version; silence/no speech N/A. Minimal pairs curated, no automatic phoneme score.
