# ENGLERN development setup (R1.1 candidate)
Install uv 0.13.10. Target Python 3.12.16, Windows x64 or macOS arm64. A reviewed uv.lock must exist before setup. Maintainers generate it with `uv python install 3.12.16` and `uv lock`, inspect it, and commit it; CI never silently regenerates it. Windows: `scripts/setup_windows.ps1`, then `scripts/run_windows.ps1`. macOS: `bash scripts/setup_macos.sh`, then `bash scripts/run_macos.sh`. Download voice and matching JSON explicitly through Voice Downloader. Native builds: corresponding build script. Older README_WINDOWS.md is historical reference only; its pip commands are obsolete. No GUI/audio/native or license qualification claimed.
