# ENGLERN 0.1.0-alpha.1 — внутренний сборочный пакет

Это исходники и автоматизация сборки, НЕ готовый установщик. Не распространять бинарники до лицензионного допуска. Модели не включены. Первые загрузки зависимостей требуют интернет. Исходный lock проверяется по SHA-256.

## Windows x64
Установите uv 0.13.10 (https://docs.astral.sh/uv/getting-started/installation/) и Inno Setup 6 (https://jrsoftware.org/isdl.php). Откройте PowerShell в распакованной папке. Выполните `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package_windows.ps1`. Если Inno установлен в другом месте, передайте `-Iscc "полный путь к ISCC.exe"`. Результат: `release/ENGLERN-0.1.0-alpha.1-win-x64-setup.exe`.

## macOS Apple Silicon
Установите uv 0.13.10. Выполните `bash scripts/package_macos.sh`. Результат: `release/ENGLERN-0.1.0-alpha.1-macos-arm64.dmg`. Перетащите приложение в Applications. Сборка не подписана Developer ID и не нотарифицирована; возможны ограничения Gatekeeper.

## Проверка на реальном компьютере
Запустите приложение, проверьте три вкладки, загрузите модель и соответствующий JSON (после проверки лицензии и происхождения), сгенерируйте WAV, воспроизведите его, перезапустите приложение и проверьте сохранность модели. Проверьте удаление; данные пользователя сохраняются отдельно от программы. GUI smoke не доказывает работу TTS или воспроизведения. Downloader исходного приложения пока не обеспечивает криптографическую проверку моделей.

CI workflow подготовлен для внутренней сборки; не активирован в публичном репозитории. Нативные сборки и установочные тесты не выполнены в Linux-окружении. Inno Setup 6.4.3 — кандидат CI, не квалифицирован. Windows installer unsigned. Для публичного распространения требуется проверка лицензий и выполнение их условий.
