# ENGLERN — English Learning Studio

Desktop language-learning studio based on Academic Audio Studio (Python 3.12, PySide6, Piper TTS).

## Targets
- Windows x64
- macOS Apple Silicon (arm64), Intel subject to qualification

## Roadmap
- R0: Import original source, excluding generated files and voice binaries.
- R1: Cross-platform setup, runtime data paths, voice downloads, native packaging and CI.
- R2: CEFR A1–C2 lesson library, sentence playback, repeat, shadowing and speed control.
- R3: Microphone recording, self-comparison and progress history.

Voice models are downloaded separately with their matching JSON configuration. Verify model licenses before redistribution.

Status: repository initialization only; source import and native qualification are pending.
