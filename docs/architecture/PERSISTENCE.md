# SQLite persistence contract
One local user, one app instance per root. sqlite3 connections thread-owned, writes serialized via repository/worker, foreign_keys=ON on every connection, WAL on local supported filesystem, busy_timeout=5000 ms; no network shared DB. Explicit short transactions, no TTS/network inside. UUID text IDs, UTC epoch ms for instants; local dates YYYY-MM-DD plus IANA timezone for plans. NOT NULL unless explicitly optional. Versioned ordered migrations, schema_history(version PK, checksum, applied_at); transactional DDL, pre-upgrade backup, rollback on failure; refuse newer schema without destructive downgrade.
Logical schema (PK id unless stated; FK restrict by default, explicit deletion workflows; indexes on FK and due/date queries):
R1: app_settings(key PK,value_json); voice_model(id,model_id,version,manifest_hash,state,path, UNIQUE(model_id,version)); audio_artifact(id,cache_key UNIQUE,path UNIQUE,model_version_id FK,bytes,created_at,last_used_at,state); pending_file_cleanup(path PK,created_at,attempts).
R2: user_profile(id,locale,timezone,level,target_level,daily_minutes); lesson(id,language,source,created_at); lesson_revision(id,lesson_id FK,revision,title,level,content_json,content_hash, UNIQUE(lesson_id,revision)); sentence(id,revision_id FK,external_id,ordinal,text,translation nullable, UNIQUE(revision_id,ordinal),UNIQUE(revision_id,external_id)); exercise(id,revision_id FK,external_id,type,config_json,UNIQUE(revision_id,external_id)); training_session(id,profile_id FK,revision_id FK,mode,state,sentence_id FK nullable,next_repeat,settings_json,active_ms,started_at,updated_at,ended_at nullable); exercise_attempt(id,session_id FK,exercise_id FK nullable,state,result_json,active_ms,created_at,completed_at nullable). Revision content immutable; references must belong to same revision, validated transactionally.
R3: recording(id,attempt_id FK,path UNIQUE,reference_artifact_id FK nullable,format_json,duration_ms,bytes,state,created_at); recognition_result(id,recording_id FK,engine_version,model_hash,normalization_version,text,metrics_json,created_at). Pin reference artifact while needed for A/B; no cache eviction of pinned files.
R4: lexeme(id,language,normalized_form,display_form, UNIQUE(language,normalized_form)); word_sense(id,lexeme_id FK,pos,meaning_key,translation,examples_json,pronunciations_json,source, UNIQUE(lexeme_id,meaning_key)); user_vocabulary(id,profile_id FK,sense_id FK,tags_json,notes,archived, UNIQUE(profile_id,sense_id)); review_state(vocabulary_id PK FK,interval_days,next_due_date,algorithm_version); review_event(id,vocabulary_id FK,rating,reviewed_at,local_date,prior_state_json,next_state_json,algorithm_version). Stable sense key; edits preserve review history; archive rather than erase by default.
R5 uses versioned lesson/exercise plus attempt rubric JSON. R6: learning_plan(id,profile_id FK,local_date,timezone,revision,algorithm_version,input_hash,budget_minutes, UNIQUE(profile_id,local_date,revision)); learning_plan_item(id,plan_id FK,ordinal,exercise_ref,minutes,reason,state,UNIQUE(plan_id,ordinal)).
Files: immutable generated UUID paths under owned root, never trust imported path. Stage, fsync where supported, atomic rename, then DB transaction referencing valid file; crash orphan cleaned by reconciliation after grace 24h (cache) or recovery prompt (recordings). DB row missing file marked UNAVAILABLE, not silently deleted. Delete DB reference and enqueue cleanup in same transaction; worker retries idempotently. No cleanup of pinned or actively leased file. Backup via SQLite backup API + consistent manifest of durable files while writes/cleanup paused; include user recordings and reference audio, exclude disposable cache/models; hash validation, restore to staging, integrity_check/foreign_key_check, switch only after validation; retain previous backup. Restore requires restart and no active jobs.
Tests: FK, duplicate ID, revision immutability, migration rollback, busy handling, crash each publish boundary, deletion retry, missing file, backup restore/corruption, timezone, repeated event dedup.
