# Alpha bundled voice
UAT: default English voice absent from installer. Support optional local bundle using ENGLERN_VOICE_DIR (Windows also -VoiceDir). The directory must contain the exact supplied pair with canonical names; hashes verified before PyInstaller. Bundled resources are read-only fallback after a complete local pair. Voice-enabled builds must synthesize WAV in both unpacked and installed GUI smoke probes. Public CI remains model-free pending explicit model redistribution review: repository MIT metadata is not sufficient to resolve the Lessac dataset research license. No model binaries committed. Source: https://huggingface.co/rhasspy/piper-voices/blob/5512791644e2148e4be301d4c7fc2a4bf51a5057/en/en_US/lessac/high/MODEL_CARD and https://www.cstr.ed.ac.uk/projects/blizzard/2013/lessac_blizzard2013/license.html .
