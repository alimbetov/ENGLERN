# UI foundation
Desktop Qt Widgets preserve existing tabs via adapters. Persistent sidebar Today, Library, Text & Audio (includes batch and voice management), Pronunciation, Vocabulary, Professional, Progress, Settings; expose only implemented modules or clearly disabled future items. Central workspace and shared player with play/pause, stop, previous/next, seek, speed, volume and current source. Training controls repeat/pause/mode; active sentence highlight plus text marker. Settings: language, theme, data/cache size, devices, models, backup, diagnostics. No network required for installed content.
UI states EMPTY, LOADING, READY, ERROR, DISABLED; long jobs show progress when known, cancel and result. Error actionable, no raw exception. Model download size/license shown before confirmation. Recording indicator persistent, explicit start/stop, no background microphone. Delete/overwrite confirmations. Keyboard Tab order, accessible names, focus indication, shortcuts Space play/pause only outside text entry, Esc cancels relevant dialog (not destructive), platform-native conventions. Color never sole status cue; system font, scalable layout, test 100/150/200% and Retina, dark/light contrast. Russian/English strings externalized, no hardcoded domain text in UI. UI updates through signals, no network/DB heavy calls in event handler.
Acceptance: existing text/batch workflows preserved, one player across navigation, errors and cancellation visible, keyboard-only lesson and recording flow, no clipped primary controls at 1280x720 logical viewport (scroll when necessary), language switch persisted. Native tests both targets.
