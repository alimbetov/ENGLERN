# ENG-CORE-01–12
All MUST requirements normative on approval. Use small Python classes/dataclasses, typed inputs/results; names illustrative until R0 mapping.
01 Application lifecycle: initialize application identity, acquire per-root instance lock, resolve QStandardPaths app data/config/cache, validate writable directories, migrate DB, reconcile files, then UI. Second instance shows existing instance or exits with clear message. On close stop new tasks, stop playback/recording (offer save/discard), cancel jobs, drain workers, close DB and lock. If native call cannot interrupt, show closing state and keep worker alive until safe completion; no QThread.terminate. Forced OS termination recovered next startup. Startup failure opens safe diagnostics, never resets data.
02 Task execution: Qt GUI/event objects owned by GUI thread; worker signals queued back; one serial TTS worker, bounded queue (initial 32 interactive jobs; batch submits incrementally), one download worker; ASR separate serial worker at R3.C. Interactive jobs ahead of pending batch items, no preemption of running native call. Queue full -> BUSY; cancellation cooperative, late callbacks gated by job/session/generation IDs. One terminal result per job. No shared SQLite connection across threads. No blocking GUI waits.
03 Audio: see AUDIO-ENGINE. Only shared playback controller owns output. Recording exclusive with playback except explicitly qualified shadowing recording (headphones recommended); MVP shadowing is simultaneous speaking without mandatory recording.
04 Models: see MODEL-LIFECYCLE. Immutable versioned bundles, trusted hashes, leases and bounded resources.
05 Persistence: see PERSISTENCE. SQLite stdlib, migrations per stage, durable user files, disposable cache.
06 Content: see LEARNING-CONTENT and schema. Preserve originals and revisions, separate display and synthesis text; no invented translations.
07 Metrics: immutable attempt/review IDs, denominator and algorithm version, distinguish zero from missing. Active time monotonic during playing/recording/explicit active exercise, pause/background idle excluded; count union of intervals not sum overlapping intervals. Session checkpoint every 5 s and at transitions; crash may lose last uncheckpointed interval. WER only for known reference; no CEFR inference. R6 rules in roadmap.
08 UI: see UI-DESIGN-SYSTEM. Russian/English, light/dark, keyboard and HiDPI.
09 Dependencies: see DEPENDENCY-BASELINE. Lock and native evidence, optional groups, no silent upgrades.
10 Errors: structured code, recoverable flag, localized summary, diagnostic correlation ID; codes INVALID_INPUT, BUSY, MODEL_MISSING, MODEL_CORRUPT, NETWORK, DISK_FULL, PERMISSION, AUDIO_DEVICE, CANCELLED, DB_MIGRATION, UNSUPPORTED, INTERNAL. Network retry max 2 automatic retries with backoff 1/2 s for transient errors; not integrity/permission errors. No raw lesson/recording text, tokens or personal paths in exported diagnostics by default. Local rotating logs 5 x 2 MiB; no telemetry.
11 Import/export: UTF-8 TXT/JSON/CSV, WAV; validate schema and size before writes, reject absolute/traversal paths, symlinks and unknown archive entries; no executable content, no remote fetch from lesson fields. Initial caps TXT/JSON 5 MiB, 100k text characters per lesson, 2000 sentences; chunk TTS at sentence boundaries within adapter limit, split long sentence safely or report explicit error. CSV formula injection guarded on export. Preview conflicts; import transaction all-or-nothing for single lesson, batch reports per item. Export to temp in destination filesystem then atomic replace only after user confirms overwrite.
12 Qualification: see ACCEPTANCE-MATRIX; exact commit, lock digest, platform/arch, model digest, test report and artifacts. PROPOSED/IMPLEMENTED/QUALIFIED/HOLD distinct. No fake PASS for skipped device checks.
